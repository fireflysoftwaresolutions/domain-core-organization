# Current Bank enrollment owner

The administrative read selects one tenant, Bank, immutable enrollment, and positive enrollment version. It returns a bounded current-owner summary from the original organization owner. It does not create an enrollment, approve a book, authorize a financial product, or establish currency or posting admission. The source implementation is default off. Signed end-to-end qualification and generated SDK delivery are separate gates.

`GET /api/v1/organization/tenants/{tenantId}/banks/{bankId}/enrollments/{enrollmentId}/versions/{version}/current` returns JSON with `Cache-Control: no-store`. The summary preserves the exact owner identifiers, version, institution, issuer, use metadata, current control version, native generations, and the original owner `currentUntilEpochMillis` timestamp. A separate `observationUntilEpochMillis` only narrows that timestamp by actual caller, machine, inherited transport and monotonic limits. Consumers must retain this effective handoff limit before final authorization and delivery; neither timestamp is a permission. An exact suspended or withdrawn owner returns HTTP409. Missing or withdrawn administrative authority returns HTTP403. An unavailable, malformed, stale, cacheable, or out-of-scope source returns HTTP503.

The service obtains the current signature-validated principal through Jafly's security SPI. Its projected tenant must equal the requested resource tenant. Current policy must permit `organization.bank.enrollment.owner.current.read` on the exact tenant/Bank/enrollment/version before the source call and before delivery, with no unresolved obligations. No actor header or request approval flag establishes identity. The optional typed `X-Firefly-Operation-Deadline` header is only a caller-supplied narrowing limit in UTC epoch milliseconds. It cannot identify an actor, grant access, or extend the domain's own caller/native lifetime. The finance terminal derives it from its original staff operation; omission starts only the independently authorized domain operation.

The original maximum ten-second budget covers principal resolution, both policy calls, machine authentication, the source request, and delivery. Caller, machine, and native absolute deadlines only narrow it; monotonic elapsed time cannot renew authority.

Activate `current-bank-owner` only with real trust, current policy, and the explicit machine environment inputs declared in `application-current-bank-owner.yaml`. The client uses standard OAuth2 client credentials, verifies the returned signed machine JWT against the configured issuer, audience, subject, client and machine tenant, and rejects staff tokens. The registration is restricted to its configured resource tenant and Bank. Machine transport credentials do not replace current caller authorization. Keep `FIREFLY_OWNER_CLIENT_SECRET` in the deployment secret store; never commit or log it. Configure the real organization base URI, token URI, JWKS URI, caller issuer/audience/JWKS, resource tenant/Bank, and the expected machine claims. All endpoints require HTTPS.

This operation has no domain-owned relational writes. Its narrow profile excludes only unused Boot JDBC/R2DBC/data-R2DBC/Flyway autoconfigurations. Existing branch adapters and workflow source remain unchanged; this profile does not qualify durable Saga storage. The shared Jafly operation budget remains the actual reviewed API; moving that generic primitive to a lightweight framework module is a separate dependency improvement.

The original parent lifecycle starts `DomainApplication`, captures its Springdoc contract, and stops it. The existing OpenAPI Generator execution consumes the resulting `openapi.yml`; canonical and compatibility resources are copied by Maven into the SDK. Generated Java and contracts must never be maintained by hand. The owned metadata gate supplies declared trust/client inputs and no successful provider response. Actual TLS/JWKS/OAuth/OPA and terminal integration remain distinct runtime acceptance.

The enabled default policy backend is the real Jafly `OpaPolicyDecisionAdapter`, imported before the resource-server default. Configure `FIREFLY_OWNER_POLICY_BASE_URI` and `FIREFLY_OWNER_POLICY_DECISION_PATH`; HTTPS or explicitly owned loopback HTTP is supported for OPA. The feature defaults off and an explicitly provided production `PolicyDecisionPort` takes precedence without binding an unused endpoint. The plain endpoint record is not a global configuration-properties bean, and its nested default backend is not independently component scanned. The metadata build configures this real backend without fabricating a policy response.

Core explicitly declares the managed Spring Security JOSE module for its JWT decoder APIs. Web declares its own actual test libraries. The original module build remains the authority on the complete dependency graph; an aggregate source compile alone cannot prove that graph.
